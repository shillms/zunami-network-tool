# Docker Network Profiler & PlantUML Generator (Zunami x FEFU)

Инструмент для автоматического профилирования сетевых взаимодействий Docker-контейнеров на хост-машинах и генерации редактируемых архитектурных схем в нотации **PlantUML** с экспортом выбранных участков в **PNG**.

## Архитектура проекта

Проект разделён на два независимых модуля, связанных единым контрактом данных (`shared/`):

1. **`profiler/` (Кейс 1 — Сборщик и анализатор сетевого трафика):**
   - Легковесный агент для хост-машин с Docker (с минимальным потреблением памяти).
   - Отслеживает внутренний (межконтейнерный) и внешний (`external`) сетевой трафик за заданное окно наблюдения.
   - Классифицирует активность контейнеров (`active`, `idle`, `frozen`, `stale`) и уровень нагрузки (`high`, `medium`, `low`, `none`).
   - Поддерживает ручные переопределения (`manual_override`) для редких/замороженных контейнеров (например, запускаемых раз в месяц), чтобы не терять важные сервисы при очистке.
   - Сохраняет итоговый снимок сети в JSON-формате по контракту `shared/schema.json`.

2. **`diagram-generator/` (Кейс 3 — Генератор схем PlantUML и экспорт в PNG):**
   - Принимает JSON-снимок от профайлера по единой схеме.
   - Генерирует читаемую, редактируемую архитектурную схему в нотации **PlantUML** (`.puml`) с группировкой по хостам/контурам и отображением статусов и связей.
   - Позволяет выбирать и вырезать отдельные участки/подграфы (фильтрация по хостам, статусам, конкретным сервисам и глубине связей) для документации.
   - Экспортирует выбранный участок схемы в **PNG** (бонусный функционал).

3. **`shared/` — Единый контракт данных:**
   - `SCHEMA.md` — описание сущностей, статусов и правил классификации.
   - `schema.json` — JSON Schema для валидации снимков между профайлером и генератором схем.
