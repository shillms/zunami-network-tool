# zunami-network-tool
Docker Network Profiler &amp; Graph Visualizer (FEFU &amp; Zunami 2026)
Проект в рамках проектной школы ДВФУ & Zunami (25.11.2026 — 18.12.2026).

## Кейсы
* **Кейс 1 (сложный):** Локальный Docker Network Profiler — сбор данных о контейнерах и сетевом трафике, выявление «мёртвых» узлов, экспорт в JSON/CSV.
* **Кейс 2 (средний):** Визуализатор абстрактных сетевых графов — интерактивный 2D/3D-граф по JSON-файлу с фильтрами, поиском и алертами.

## Структура папок
* `profiler/` — код агента, сборщика метрик и эмулятора сети (команда Кейса 1).
* `visualizer/` — код веб-интерфейса и отрисовки графа (команда Кейса 2).
* `shared/` — общие примеры JSON-файлов и описание единого формата данных между сервисами.

## Правила работы с Git
* `main` — основная ветка со стабильным рабочим кодом. Прямые пуши сюда закрыты.
* `dev/profiler` — рабочая ветка для команды Кейса 1.
* `dev/visualizer` — рабочая ветка для команды Кейса 2.

### Порядок работы:
1. Перед началом работы всегда делаем `git pull`, чтобы забрать свежие изменения.
2. Работаем в ветке своего кейса (`dev/profiler` или `dev/visualizer`) или в своей отдельной ветке от неё.
3. Пишем код только в папке своего кейса (`profiler/` или `visualizer/`), чтобы не мешать друг другу.
4. Когда задача готова — открываем Pull Request в `main` на проверку тимлиду.
